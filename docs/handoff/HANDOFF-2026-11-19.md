# Handoff 2026-11-19 — v0.3.2

Release v0.3.2 is integrated in `work/dynabrothers` (PR #72). **The only open goal is the remaining DB2 dialogue translation, planned for v0.4.** Everything below is done unless marked otherwise.

## What v0.3.2 changed (and where)

- **DB2 gameplay 16:9 never flips to 4:3** — `games/db2_video.c`
  - Held camera pans (B + D-pad): the VDP scroll moves in 16 px sub-steps while the RAM camera cell moves every 32 px. The terrain is re-aligned from the displayed VDP scroll (`off_x/off_y`, constant `kx/ky` learned on accepted frames, self-healing search on a mismatch). Pan route: 40/53 frames 4:3 → 0.
  - Prompt banner sprites (patterns 370–47F, size 0F, palette 1/2) are world-view sprites.
  - A visible SAT entry without a known owner keeps its native pixels (HUD column ≥216 or world) instead of rejecting the frame.
  - Up to 3 consecutive rejected battle frames re-present the last widened frame (`held`).
  - Trace: `DYNA_DB2_VIDEO_TRACE=2` prints one `[db2-frame]` line per frame (reasons, RAM vs VDP scroll) and `[db2-reject]` for the sprite that caused a rejection.
- **Non-battle screens fill 16:9**
  - `games/db2_wide_menu.c`: margins from the guest's own planes/sprites. Dense art authored wider than the 40-column window continues by repeating its edge block (intro); sparse planes (dialogue boxes) never repeat.
  - `db2_video.c` `vertical_finish()`:
    - Intro / empty-margin map scenes: DB1-intro fade at the original 320 px borders, with vertical extension.
    - Sky on line 0 (title, main menu): image anchored to the bottom, sky continued upward.
    - Framed submenus: `panel_stretch()` (DB1-style), a sticky choice of one wide-interior column per side; the gap is that column's colour, or the nearest interior line's colour, never a copied block.
- **Main menu in English** — `games/db2_menu_labels.c`
  - Finds the 4 plates by the shared "モード" tiles 17F–184/18F–194 in plane A.
  - Paints the stone fill tile 0x265, then PRACTICE/STORY/ORIGINAL/VERSUS with PASSWORD-style 16×16 glyphs, inked per scanline with the original row colours.
  - Works in 4:3 (overlay_scanline) and 16:9.
- **Practice titles numbered** — the `ram_text` line is `PRACTICE #`; `#` copies the digit word after the matched prefix (`games/db2_glyph_text.c`, digit = (w-0xCC)/2).
  - **Not seen on screen yet**: confirm Practice 1/2/3 show their own number.
- **Package layout** — `tools/package_checkpoint.py`
  - Root: `DynaBrothers.exe` (`games/root_stub.c`, system DLLs only) + `data/` (launcher, games, DLLs, assets, debug, licenses, PACKAGE.json, saves/settings) + `roms/`.
  - The launcher detects it runs from `data\` and scans ROMs from the parent (`root_dir`).
  - `verify_checkpoint.py` and `close()` read from `data/` when present.
  - Users upgrading must copy `.srm`/`settings.ini` into `data/`.
- **Launcher flicker** — `games/checkpoint_launcher.c`
  - Owner-drawn cards/pills render into a memory DC and blit once (`draw_item`).
  - **Needs confirmation with a physical controller.**
