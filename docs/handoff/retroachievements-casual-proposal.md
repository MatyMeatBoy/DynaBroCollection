# RetroAchievements Casual eligibility request

We maintain DynaBroCollection, a Windows x64 project that recompiles Dyna Brothers and Dyna Brothers 2 Special from player-supplied Sega Genesis ROMs. The runner retains guest RAM and VDP state and presents an optional enhanced widescreen view. It has its own local achievement profiles and development builds can use scripted input and diagnostic memory editing.

Would RetroAchievements consider allowing this project to use the existing Genesis set for Dyna Brothers in Casual mode only? If so, which integration and review path would you require for a native recompiler? The existing Dyna Brothers set is game 5362. The project's custom Dyna Brothers 2 Special achievements would remain local.

For initial review, the proposed opt-in integration would identify a recognized, unmodified ROM, use the approved client and official achievement definitions, and evaluate guest memory during normal play. Development and scripted sessions would remain local. The client would never submit unlocks imported from the existing local profiles, and it would never claim Hardcore support. We would ask you to review English-patched ROMs separately before connecting those sessions.

We understand the published Standalone rules exclude unofficial recompilations. This request is to establish whether any reviewed Casual-only path is available before implementing or shipping network unlocks.
