## Scope and limits

This is a test checkpoint. Physical audio/M30 firmware acceptance, complete campaigns and complete translation coverage remain unverified. Save Game stores verified native codes, not arbitrary midbattle snapshots. Replay requests require the native Password screen. Extras is currently in the host in-game menu, not an inserted original title-menu entry. Seven DB1 guide captures are included with declared fixture provenance; numeric combat statistics remain unverified.

DB2 current renderer is integrated and its existing regressions pass, but further DB2 work is paused by explicit user request. Its unsupported layers/scenes use native fallback; full native widescreen visual qualification is not claimed. Later documentation commits do not change the compiled source or this immutable archive.
