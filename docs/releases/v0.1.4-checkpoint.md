# Dyna Brothers v0.1.4 — test checkpoint

This checkpoint is published as a prerelease; see [closed verification](v0.1.4-verification.md). It is not a final port or a claim that every translation, scene and effect is complete.

## Principal changes

- DB1 sound driver can observe YM2612 Timer A; sustained non-DC mixer audio is checked rather than only counting audio frames. Physical output on the reporter PC remains a hardware test.
- DB1 extended world composes terrain and actors beneath transparent HUD pixels, avoiding duplicated native sprites. Integer-fill canvas targets1080p,1440p and4K while preserving original simulation timing.
- Enhanced DB1 title/options/password/stage intro/gameover have scene-aware presentation. Weather and lightning receive focused native reproduction checks.
- Automatic keyboard+controller source, six-button defaults and the reported M30 XInput bindings. Known M30 IDs have profiles; generic Xbox identities cannot identify the physical model and use the configured SDL bindings honestly.
- Start+Mode/Select opens the host menu. Start alone remains native. Analog menu navigation and closing-button capture are implemented.
- Full settings can render in the existing game window. Main hub has the approved rock/volcano logo and genuine engine screenshots, plus integration flags.
- Extras contains Level Selection and Game Guide, with short two-page Basic and Advanced strategy text. Progress codes can be saved atomically; native password-screen replay queues a saved code through the original parser.

## Install and controls

Keep all extracted files together. Start DynaBrothersLauncher.exe. Supply your own supported Japanese ROMs; no ROM is included. English is enabled by default and remains partial. Retain your previous checkpoint and profiles while testing.

M30 generic XInput defaults: A=A,B=B,C=right trigger,X=X,Y=Y,Z=right shoulder,Start=Start,Mode=Back. Directions use left axes or D-pad. Six-button protocol is the default; manual bindings remain configurable. Use Start+Mode for the host menu, then Full Settings for all launcher panels in the same window.

## External launcher integration

DynaBrothersLauncher.exe accepts --game db1|db2, --rom PATH, --no-launcher, --setup, --fullscreen and --widescreen off|16:9|fit. --integration-info prints machine-readable JSON. Quote ROM paths containing spaces. A direct launch with a ROM skips setup unless --setup is requested.

## Known limits

DB2 renderer work is integrated and deliberately paused at the user's request. It has synthetic world/actor/HUD tests, including actor41 outside the native width, but no full native visual qualification. Unsupported layers/effects fall back to the native view; title/intros/gameover are not fully extended. Do not interpret integration as completion of DB2 widescreen.

Extras is currently a host in-game menu addition; original cartridge title-menu insertion is unfinished. Level replay requires visiting the native Password screen; it does not jump the guest PC. Arbitrary midbattle save states and rewind remain disabled. Progress files are specific to the effective ROM image, including the language variant. Seven DB1 guide captures are included with reproducible inputs and provenance; DB2 guide captures and numeric unit statistics remain work in progress.

No claim of complete campaign, physical M30 firmware compatibility, or audio-device acceptance is made by automated fixtures. Report game/mode/scene, resolution, controller identity, logs and feedback replay with failures. Never overwrite your original ROM.
