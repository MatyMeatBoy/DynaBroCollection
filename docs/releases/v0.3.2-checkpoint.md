# Dyna Brothers v0.3.2 checkpoint

DB2 widescreen and English presentation pass, launcher polish and a tidy package layout.

- Package layout: only `DynaBrothers.exe` at the root, plus `data/` (launcher, games, runtime, assets) and `roms/` (put your own dumps there). Saves and settings live in `data/`; copy `.srm`/settings files from an older install into `data/` to keep them.
- Launcher: game cards and buttons are drawn off-screen and copied in one step, so moving between them with a controller no longer flickers.

- Gameplay 16:9 no longer flips to 4:3: held camera pans (B + D-pad) follow the VDP scroll sub-steps, the gameplay prompt banner is recognised, unknown SAT entries keep their pixels in place, and a brief rejection re-presents the last widened frame.
- Intro, title, main menu and submenus fill 16:9: plane art past 4:3 is shown; the intro fades its original side borders like DB1 and extends vertically; the title anchors to the bottom with the sky continued above; framed submenus stretch like DB1 (frame outward, text and cursor unchanged); map scenes with nothing outside 4:3 fade their sides.
- Main menu modes read PRACTICE / STORY / ORIGINAL / VERSUS in the PASSWORD/OPTIONS lettering style with the original row colours.
- Practice briefing titles show their real number instead of always "PRACTICE 4".

Planned for 0.4: translating the remaining in-stage event dialogue (for example Mission 1 and the Info View map labels).
