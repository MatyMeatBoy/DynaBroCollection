# Dyna Brothers v0.4.3

- DB2 uses the same stone background behind the English menu labels throughout the title scroll. Skipping the title clears the parked Sega Channel logo from the left edge. The title art retains its original bilingual branding.
- DB2 restores the intro's side fade. Pausing and entering a Classic stage keep the widescreen HUD in place.
- Start + Select offers **Return to Title** and **Quit Game** in both games. Both actions ask for confirmation. Return to Title restarts the native boot sequence and skips the intro where the cartridge accepts Start.
- When the window loses focus, the game clock continues independently of display synchronization.
- RecompLauncher can set up and start each game from its own ROM and change the display mode, filtering, volume and language.

Place your own compatible Japanese cartridge dumps in the `roms` folder and open `DynaBrothers.exe`.
