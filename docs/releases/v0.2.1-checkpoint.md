# Dyna Brothers v0.2.1 — Windows x64 alpha

Run DynaBrothersLauncher.exe with the extracted files together. Public packages require supported original dumps in roms/ or the executable folder. The private personal package includes the owner's original dumps. English defaults on.

This alpha release preserves v0.2.0's DB1/DB2 features and adds a Settings > Manual viewer to the launcher: a book-sized, GDI-drawn open booklet (paper leaves, a staple-bound spine, a stacked-page edge) with PDF-reader pagination -- the cover shown alone, then real facing pairs -- and a JP/EN toggle that swaps the right-hand page between its own Japanese scan and the English translation. The viewer auto-detects whether a given DB2 manual scan is a single portrait page or an already-joined two-page spread (some of DB2's interior pages were scanned with the physical fold already in frame) and renders each correctly. The whole feature, including the Manual button itself, is reachable by gamepad D-pad, not just mouse and keyboard.

DB2 gets the same native-rendering fix DB1 received in v0.2.0: a single actor whose record is transiently unreadable (for example the frame it dies on) no longer drops the entire frame back to the native fallback image -- only that one actor's own sprite is skipped for the bad frame. This was confirmed live with a 12,000-frame battle-play capture showing the fallback trigger firing during ordinary gameplay, not only the already-documented pre-battle window, and verified to leave guest/audio state hashes unchanged (a host-presentation-only fix).

The DB2 Special translation catalog grows from 582 to 704 entries: stage-2 RAM cutscene dialogue, password-screen fixes, a stage title, and assorted briefing leftovers from v0.2.0.

Known remaining DB2 gaps are unchanged from v0.2.0: the in-game Options menu's text and Original mode's kanji stage names are suspected baked tile graphics, not ROM text. Also unchanged: a subtle, low-severity graphical glitch on fast-moving DB1 actors near the HUD/world-viewport seam, and a DB1 title-menu highlight-timing question around the Extras row wraparound (both have concrete, code-level investigation notes in `docs/handoff/PENDING.md`, not fixed blind). See [STATUS.md](../../STATUS.md) and `docs/handoff/PENDING.md` for the full list and the evidence behind each item.

The green launcher contains settings for either game. Start+Mode/Select opens the in-game host menu, which now also offers Restart Level, Return to Title Screen and Quit to Desktop. Known M30 identities select the Genesis six-button layout; physical firmware variants still require hardware testing. Original preserves 4:3. Enhanced targets 16:9.

Verification includes the full native contract suite and Python test suite, both green on this alpha. Packaged checks additionally exercise an actual typed Normal2 password and B+direction camera route in six-button mode, comparing Original/Enhanced canonical guest and audio state. Exact packaged results are recorded in PACKAGE.json after qualification.

Known limit: DB2 can temporarily fall back to the native image during held camera movement and initial frames. Released camera captures preserve exact world and HUD pixels at their projected offsets. Continuous widened scrolling, whole campaigns, all hazards and physical audio/controller output are not claimed complete. DB2 English remains partial. This is an alpha release, not a finished recompilation.

A separate private development toolkit restores sources, pinned dependencies, portable tools, private inputs and generated code on another Windows x64 PC. Read docs/handoff/CONTINUE-ON-ANOTHER-PC.md. Keep private packages and toolkits private.
