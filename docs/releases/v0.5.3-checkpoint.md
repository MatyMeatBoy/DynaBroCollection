# Dyna Brothers v0.5.3 Beta

- Launcher Settings → Video gains a Texture filter row (Nearest / Bilinear), next to VSync (On / Off / Adaptive), integer scaling and the window controls.
- Includes everything from v0.5.2:
  - no doubled units while panning;
  - faster DB2 menus, stage list and Versus selector;
  - borderless launcher with a logo intro;
  - Back from Settings returns to the selector;
  - System last in Start+Select;
  - DB1 always uses the three-button pad.

This build is Windows x64. Linux, macOS and Android stay on v0.5.0 Beta 1 until they are rebuilt on their platforms.

Bring your own compatible game dumps. The release does not include ROMs.
