# Dyna Brothers v0.5.5 Beta

- Dyna Brothers uses the full widescreen canvas during the victory animation and the Aliens Ejected result.
- Wins save progress automatically. The victory result shows a yellow **Game Saved** notice with a disk icon and offers **Continue** and **Back to Title**.
- The level selector lists every unlocked numbered stage through the saved checkpoint. For example, an existing Normal 2 save shows both Normal 1 and Normal 2.
- Clearing Normal 20 unlocks Hard 1. Clearing Hard 20 unlocks the original Reverse entry, Back 1 (MHRI). Both unlocks are saved before the ending finishes.
- DB1 progress files use the same ROM identity on Windows, Linux, macOS, and Android.

Bring your own compatible game dumps. Android uses the same parallel beta app and signing key as v0.5.4.
