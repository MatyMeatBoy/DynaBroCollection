# Dyna Brothers v0.5.2 Beta 1

- DB2: units no longer appear doubled or "blended" while you pan the camera with B + D-pad (seen in SEGA CHANNEL SPECIAL stage 1 and elsewhere).
- DB2: the Original and Versus menus no longer stutter (about 3x faster composition).
- Launcher:
  - opens borderless and full screen by default;
  - plays a short fade-in intro of the 1+2 logo before the game selector (any key, click or button skips it);
  - draws its artwork much faster, with no stutter when moving between games.
- "Skip launcher on boot" keeps your saved choice and is off by default.
- In-game Start+Select menu: the System section (Return to Title, Quit) is always last.
- DB1 always uses the three-button pad, the only one it supports. Manual mapping stays available with the "Custom" controller layout.
- VSync: on by default. Settings → Video lets you choose On, Off or Adaptive.
- Launcher Settings: Back (button, Esc or the controller) returns to the game selector. There is no second configuration screen anymore.
- DB2 stage list and Versus selector: faster composition (Versus 13.0 → 3.8 ms per frame).

This build is Windows x64. Linux, macOS and Android stay on v0.5.0 Beta 1 until they are rebuilt on their platforms.

Bring your own compatible game dumps. The release does not include ROMs.
