# Dyna Brothers v0.5.0 Beta 1

- Native packages for Windows x64, Linux x64, macOS Apple Silicon and Android arm64-v8a / x86_64.
- Both games can report newly earned achievements to Recomp Achievements during a connected session. DB1 adapts its existing 76 native challenges and DB2 uses its 99 community challenges. The existing in-game lists and locally earned progress are available offline.
- Automatic display mode starts windowed from RecompLauncher's desktop and borderless from Big Picture. The quick menu shows Xbox or PlayStation button icons based on the controller reported by RecompLauncher.
- The Windows and Linux packages use SDL3 for video, audio and controllers through the upstream SDL2 compatibility layer. macOS and Android use SDL2 in this beta.
- ROM validation identifies common setup errors. The launcher keeps recent logs and uses a per-user profile when the portable data directory is read-only.

Bring your own compatible game dumps. The release does not include ROMs.

Recomp Achievements account unlocks and rankings depend on service-side registration. The beta includes both event lists and works with an approved developer test session.
