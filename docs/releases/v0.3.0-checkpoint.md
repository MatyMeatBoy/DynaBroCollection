# Dyna Brothers v0.3.0 — Windows x64 public BETA

Run DynaBrothersLauncher.exe with the extracted files together. Public packages require supported original dumps in roms/ or the executable folder. The private personal package includes the owner's original dumps. English defaults on.

This release promotes the project to public BETA: v0.2.0/v0.2.1's translation and rendering fixes have held up under continued live testing, and the remaining open items are cosmetic, environment-dependent, or need a human with real hardware/input rather than more scripted verification work. Nothing about the underlying game logic, saves or guest state changed in this release — it closes out launcher-side bugs reported from live play and confirms the project's two integrity guards (ROM validation, translation catalog coverage).

Two launcher bugs reported from live testing of the real running app (not scripted captures) are fixed: the box-art hover/focus cartridge-reveal animation used to slide the cartridge sideways across the cover art, crossing visibly over it; it now rises straight up out of the box's open top edge instead. Separately, the launcher's own `DYNA_HUB_HOME_CAPTURE` diagnostic tool was missing the Manual button from its screenshot list (the live app itself always rendered it correctly) — fixed so future diagnostic captures are trustworthy.

The Settings > Manual viewer (added in v0.2.1) had a text-completeness bug: long translation notes — advertisement pages, rule/terrain tables — could overflow the fixed-size text panel and get cut off mid-sentence. The viewer now measures each note against its available space and shrinks the font just enough to show the whole thing, so no translated text is ever silently clipped.

ROM integrity: both games already validate the loaded ROM's CRC32 against known Japanese-original and English-translation revisions before accepting it (`games/hub_settings.c`); this release confirms that guard is exercised by the packaged regression suite and the full native/Python test suites, both green.

`tools/verify_checkpoint.py`, the packaging script's 45-case regression suite, now runs its checks in parallel (roughly 3x faster) with identical, bit-verified results — a development-workflow change with no effect on the shipped binaries.

DB1/DB2 string-level translation is complete at the catalog level (DB2 Special: 704 entries). What remains is not "more translation" but a different technical problem: (a) a few screens' text is baked as tile graphics rather than ROM strings (Original-mode kanji stage names, the "STAGE n" briefing card, main-menu row icons), which needs a new host-overlay engineering effort, not string patching; (b) a handful of screens whose text is already translated in the catalog (QUIT dialog, results, Dyna Fight, Sega Channel, endings) have not been visually confirmed on screen because no scripted input sequence reliably reaches them — tried multiple repro attempts, all dead ends; (c) native-speaker wording review and physical-hardware/controller acceptance, which need a human. See `docs/handoff/PENDING.md` for the full, itemized accounting, including several fixes from this and the prior release that are code-complete and test-covered but still await a human with real hardware to visually/behaviorally re-confirm (the in-game menu's new Restart/Return/Quit actions, the DB1 4:3-flash-on-death fix, the moving-actor HUD-seam investigation).

The green launcher contains settings for either game. Start+Mode/Select opens the in-game host menu, which offers Restart Level, Return to Title Screen and Quit to Desktop. Known M30 identities select the Genesis six-button layout; physical firmware variants still require hardware testing. Original preserves 4:3. Enhanced targets 16:9.

Verification includes the full native contract suite and Python test suite, both green on this beta. Packaged checks additionally exercise an actual typed Normal2 password and B+direction camera route in six-button mode, comparing Original/Enhanced canonical guest and audio state. Exact packaged results are recorded in PACKAGE.json after qualification.

Known limit: DB2 can temporarily fall back to the native image during held camera movement and initial frames. Released camera captures preserve exact world and HUD pixels at their projected offsets. Continuous widened scrolling, whole campaigns, all hazards and physical audio/controller output are not claimed complete. DB2 English remains partial. This is a beta release, not a finished recompilation.

A separate private development toolkit restores sources, pinned dependencies, portable tools, private inputs and generated code on another Windows x64 PC. Read docs/handoff/CONTINUE-ON-ANOTHER-PC.md. Keep private packages and toolkits private.
