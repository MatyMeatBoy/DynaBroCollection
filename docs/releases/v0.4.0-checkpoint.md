# Dyna Brothers v0.4.0 checkpoint

DB2 Info View in English, 16:9 stage briefings, and per-game icons.

- Info View (button A inside a stage) is now English: TERRAIN MAP / CHARACTER MAP / EGG MAP, the TIRING / DAMAGE / DEADLY / SPECIAL AREA and BURNS / NOBURN legend, the TRIBE / EGG / GIVEUP and ALLY / FOE bars, the OK? / REALLY? confirmation and the unit-name table.
- Stage briefing screens (STAGE n) fill 16:9: the backdrop colour continues beyond the original 4:3 window while the original pattern and panels stay untouched.
- Icons: DB1's executable carries the stone "1", DB2's the stone "2", and the launcher / DynaBrothers.exe the stone "1+2" logo (also used as the in-game window icon).
- Package layout unchanged from 0.3.2: `DynaBrothers.exe` + `data/` + `roms/`. The English DB2 ROM identity is now CRC32 DE76C2B8; the launcher recognises it.
