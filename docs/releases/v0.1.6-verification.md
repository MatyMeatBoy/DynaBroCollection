Final qualification reran all cases with ASCII diagnostic output names and a separately named Unicode profile. It uses the same frozen package, not rebuilt or substituted executables. ## Limits and next source work

English remains partial. DB2 keeps the previously integrated base, pending DB1 readiness. Physical M30 firmware variants, actual reporter-PC audio playback and complete campaign/achievement acceptance remain unverified.

Native title-menu Extras, its new catalogue/navigation integration and graphical P-chan speech work were developed after this package was frozen. They are not in0.1.6. The package does include result-screen Save/Continue, original-size visor placement, title/story corrections, verified unit guide and the green launcher fixes described in its checkpoint notes.

A separate private personal ZIP contains the user's original dumps and passed automatic discovery from its own portable working directory without --rom flags, with isolated settings and no development DLL paths. It must never be uploaded. Public and personal binaries are identical.

## Subsequent findings and replacement test checkpoint

Later native font tracing found five hard-ending punctuation slots overwritten
at runtime, and the special EMI code's native blank padding needed an exception
in validation and deferred END confirmation. These limitations remain in the
immutable0.1.6 archive. Both are corrected and packaged in [0.1.7](v0.1.7-verification.md),
which also includes the newer native Extras/navigation and graphical speech.
The older archive is preserved rather than silently replaced.

## Later DB2 automation scope correction

A native driver audit after0.1.7 publication identified the historical DB2
unpause fixture as an attract/demo route. Its finite control-flow/hash results
remain valid, but it does not prove player-controlled gameplay. See the
[exact scope correction](db2-demo-fixture-scope.md). Archive bytes and recorded
hashes remain unchanged; actual interactive acceptance is being qualified separately.
