# Dyna Brothers v0.1.7 — Windows x64 test checkpoint

English is enabled by default. Keep the extracted folder together and run DynaBrothersLauncher.exe. Public packages contain no ROMs: put supported original dumps in the executable folder or roms/. A separate personal package may contain its owner's dumps and must stay private.

## New in this checkpoint

- DB1 Enhanced title adds Extras in the native pixel-art menu. Level Selection offers Practice, Normal and Hard starting stages, earlier stages through a validated saved frontier, saved Back progression and individually saved Alien stages.
- Selecting a level from the title navigates the original Password screen automatically. Cancellation, held-button release and timeout preserve native input and transitions. Replay availability never awards achievements.
- Existing DB1 saves from supported English revisions are imported into one language-independent identity. Legacy files remain untouched. Save files store native progress codes, not arbitrary midbattle snapshots.
- Eight P-chan graphical speech frames are translated. Five punctuation characters in the hard ending use the font actually loaded there. Current English CRC2740C64E; previous supported inputs remain accepted and Japanese remains selectable.
- The special EMI password keeps its original three-letter form and blank padding. It can be selected after saving its native result screen.
- Original 4:3 English title uses the approved translated stone logo. Its layout, native four-row menu and game clocks remain unchanged.

## Presentation and controls

Original preserves4:3. Enhanced expands the visible world while preserving the original command visor and effect rules. Visor position moves in whole8px tiles, defaults to balanced margins and clamps at safe borders. Rain/damage keep their native area; lightning visuals follow the original separate visual bounds. HUD remains at the right. Added visible space does not speed up simulation.

Settings opens inside the green launcher. In-game host menu uses Start+Mode/Select; Start alone keeps native pause. Known M30 identities use six-button Genesis mappings automatically. XInput layout: A=A, B=B, C=right trigger, X=X, Y=Y, Z=right shoulder, Start=Start, Mode=Back. Generic Xbox identity can require manual bindings.

At a native password result choose Save or Continue. The timed hard ending offers Save and retains its original timer. Extras includes the unit guide, HUD/hazard explanations and short basic/advanced strategies with game-engine examples.

External setup: --game db1|db2, --rom PATH, --no-launcher, --setup, --fullscreen, --widescreen off|16:9|fit; --integration-info describes launcher integration. Quote paths containing spaces. Mods discovered on disk are informational unless explicitly supported by the static build.

## Verification and limits

This is a test checkpoint. Source checks include50 CTests,67 Python tests and an85-destination native load matrix. Loading is not campaign completion. Exact packaged checks and identities are recorded with the closed package; pre-release source results do not substitute for packaged verification.

Physical M30 firmware variants, reporter-PC audio output and exhaustive campaign/achievement acceptance remain separate from local automated evidence. DB2 retains its previously integrated base while DB1 is qualified; this release rebuilds its shared runtime without claiming new DB2 gameplay fixes.

For portable DB1 diagnostics run debug/Test-DB1-16x9.ps1. Preserve original dumps and include scene, resolution, controller identity and feedback logs with reports. Do not share ROMs or personal packages publicly.
