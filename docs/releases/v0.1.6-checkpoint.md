## Run and configure

Keep the extracted folder together and run DynaBrothersLauncher.exe. Put supported ROMs in the executable folder or roms/; configured paths are also scanned. Settings opens inside this same green hub. PLAY launches the selected game. In-game host menu uses Start+Mode/Select; Start alone retains the native pause.

Original mode preserves4:3. Enhanced uses an integer-scaled panoramic canvas. In DB1 Widescreen settings, Visor position (tiles) defaults to0, balancing the visible side margins. Positive/negative values move by8px tiles within safe borders. The native command area stays192x192; additional world visibility does not expand rain or damage targets. The HUD stays at the right.

At a native result-code screen choose Save or Continue with Up/Down and A/C/Start. Release a held button first. The timed hard-ending screen has Save only and retains its original timer. Progress is stored as validated native codes, not arbitrary midbattle save states. Current Extras level replay still requires reaching the original Password screen.

Known M30 mappings are automatic where device identity distinguishes the controller. XInput face layout: A=A, B=B, C=right trigger, X=X, Y=Y, Z=right shoulder, Start=Start, Mode=Back. A generic Xbox identity cannot prove the physical controller model; manual bindings remain available.

External integration supports --game db1|db2, --rom PATH, --no-launcher, --setup, --fullscreen and --widescreen off|16:9|fit. Use --integration-info for metadata and quote paths with spaces. Informational BPS/IPS discovery does not apply arbitrary patches to the static executable.

Portable debugging: debug/Test-DB1-16x9.ps1. Include game, scene, resolution, device identity and feedback logs when reporting an issue. Keep original dumps unchanged.
