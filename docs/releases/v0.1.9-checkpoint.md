# Dyna Brothers v0.1.9 — Windows x64 checkpoint

Run DynaBrothersLauncher.exe with the extracted files together. Public packages require supported original dumps in roms/ or the executable folder. The private personal package includes the owner's original dumps. English defaults on.

This checkpoint preserves v0.1.8 DB1/DB2 features and expands the DB2 Special English translation from 22 gameplay prompts to 454 catalog strings (menus for Original/Versus/Sega Channel/Password/2P setup, story-mode dialogue, stage briefings, VS character/control screens) plus a new host biography overlay (`games/db2_bio_overlay.c`) that renders creature name/stats/flavor text in English over the native 8x8 menu font, decoded live from the ROM's own dictionary stream. A title-menu highlight bug is fixed: selecting Extras stayed hover-yellow after its panel opened instead of returning to the unselected white every other row uses.

Known remaining DB2 gaps: the in-game Options menu's text (music/sound/button-layout labels) is not reachable through either known glyph-rendering hook and is suspected to be baked tile graphics rather than ROM text; Original mode's kanji stage names and the graphical "STAGE n" briefing title cards are the same class of problem. A host-side SAT producer-epoch tracker (`db2_video_producer_epoch`) was added as diagnostic-only groundwork for a documented but not-yet-implemented widescreen coherence fix (`evidence/db2-visor-research/coherence.md`). See [STATUS.md](../../STATUS.md) and `docs/handoff/PENDING.md` for the full list and the evidence behind each item.

The green launcher contains settings for either game. Start+Mode/Select opens the in-game host menu. Known M30 identities select the Genesis six-button layout; physical firmware variants still require hardware testing. Original preserves 4:3. Enhanced targets 16:9.

Verification includes 53 native contracts and 111 Python tests. Packaged checks additionally exercise an actual typed Normal2 password and B+direction camera route in six-button mode for 9400 frames, comparing Original/Enhanced canonical guest and audio state. Exact packaged results are recorded in PACKAGE.json after qualification.

Known limit: DB2 can temporarily fall back to the native image during held camera movement and initial frames. Released camera captures preserve exact world and HUD pixels at their projected offsets. Continuous widened scrolling, whole campaigns, all hazards and physical audio/controller output are not claimed complete. DB2 English remains partial. This is a checkpoint, not a finished recompilation.

A separate private development toolkit restores sources, pinned dependencies, portable tools, private inputs and generated code on another Windows x64 PC. Read docs/handoff/CONTINUE-ON-ANOTHER-PC.md. Keep private packages and toolkits private.
