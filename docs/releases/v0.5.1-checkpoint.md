# Dyna Brothers v0.5.1 Beta 1

- DB2: the title and mode menu now look the same whether you wait for the intro or skip it with START (for example when entering with a controller). Skipping used to leave the mode plates in Japanese, show a strip of stray tiles at the top and bottom and a piece of the title logo in the left margin. Cause and fix: `docs/handoff/title-skip-fix.md`.
- DB2 window/executable icon shows the whole stone "2".
- Portable by default: saves, settings and logs stay in `data/` next to the games (a per-user profile is used only when that folder is read-only).

This build is Windows x64. Linux, macOS and Android packages remain on v0.5.0 Beta 1 until they are rebuilt on their platforms.

Bring your own compatible game dumps. The release does not include ROMs.
