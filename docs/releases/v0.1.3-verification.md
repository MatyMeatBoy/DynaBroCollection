## Limits

This checkpoint does not certify complete campaigns, every effect/animation, physical M30 transports/firmwares, physical audio or physical 4K display testing. Resolution tests cover canvas/integer geometry. Both translations remain partial. DB2 has no expanded-world renderer in this version. Extremely wide aspects can exceed the native randomized-decoration ring. Save states and rewind remain disabled.

DB1's 76 local goal contracts are an independent implementation of the public goals, not imported authenticated RetroAchievements evaluator definitions. The 99 DB2 Special goals are a custom local set. Neither synchronizes accounts. See [checkpoint instructions](v0.1.3-checkpoint.md), [DB1 contracts](../db1-achievement-contracts.md) and [DB2 contracts](../db2-achievement-contracts.md).
