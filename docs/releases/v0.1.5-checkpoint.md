# Dyna Brothers v0.1.5 — test checkpoint

Windows x64 prerelease focused on DB1 widescreen continuity and the shared green launcher. English remains enabled by default and partial. Supply your own supported ROMs; public packages include no ROMs.

## Changes

- One green launcher: each game's settings opens inside the original hub window. In-game settings use the same green theme, game artwork and approved volcano logo. Controller navigation and high-DPI rendering are corrected.
- Supported ROMs are recognized automatically in the executable folder, roms/mods folders, saved paths and configured paths.ini locations. Explicit --rom selections are respected. External BPS/IPS files appear as informational discoveries; built-in language support provides the qualified English translation.
- DB1 camera geometry is coherent across frames: scrolling no longer introduces the reproduced actor phase jumps. Stage terrain is extended from the initial fade, text stays centered and the falling egg is drawn once.
- Options, password and map submenus extend their authored backgrounds and frames without copying legend icons or black uninitialized tiles. Native foreground pixels and gameplay timing are preserved.
- Branding margins follow the original black/white palette fades. The English title uses the approved stone logo; Japanese retains its original title. Generated art fills only missing title-background bands and follows native scrolling/fades.
- Disaster rendering includes full-width lightning, tsunami and the other verified disaster-menu routes. Audio Timer A and automatic six-button/M30 profiles from0.1.4 are retained.
- Native password replay has been exercised successfully, including cancel and timeout. This does not claim completed save/Extras user experience.

## Running

Keep the extracted directory together and run DynaBrothersLauncher.exe. Settings opens inside this same window; PLAY starts the selected game. Start+Mode/Select opens the in-game host menu. Start alone remains the game's original pause.

The external integration flags remain --game db1|db2, --rom PATH, --no-launcher, --setup, --fullscreen and --widescreen off|16:9|fit. --integration-info prints supported options. Quote paths containing spaces.

Original mode retains4:3. Enhanced targets16:9 with the largest supported integer scale and additional world canvas. At1440p the qualified logical canvas is427x240, filling the missing vertical area as well as the sides.

M30 XInput layout: A=A, B=B, C=right trigger, X=X, Y=Y, Z=right shoulder, Start=Start, Mode=Back. D-pad and left axes work. Known identities have automatic profiles; a generic Xbox identity cannot identify its physical model. Manual bindings remain available.

## Remaining work

DB2's existing renderer is integrated, and further DB2 game development remains paused. Do not interpret this release as complete DB2 widescreen qualification. Native title-menu Extras insertion, complete save/level-selection UX, verified numeric unit statistics, remaining English text and full campaign achievement acceptance are still open. Level replay currently requires visiting the native Password screen. Physical M30 firmware and other-PC audio-device acceptance require hardware confirmation. Arbitrary midbattle save states and rewind are disabled.

The included debug/Test-DB1-16x9.ps1 provides the portable comparison test. Reports should include game/scene, resolution, controller identity and feedback logs. Never overwrite your original dumps.
